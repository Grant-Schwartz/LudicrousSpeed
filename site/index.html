LudicrousSpeed

A Rust engine recalculates your model off-thread, without changing a single formula in it — built for the workbooks where a sensitivity table means a coffee break.

How it actually works

  1. 01

    Snapshot the model

    Analyze Workbook or Recalculate saves a temporary copy of the live .xlsx. Warm runs skip even that and send only the cells that changed.

  2. 02

    Recalculate in Rust

    The snapshot loads into a Rust engine built on IronCalc, which evaluates the full model off Excel's own calculation thread.

  3. 03

    Stream results back over RTD

    Excel won't let anything set a formula cell's cached value in place — three different approaches were tried and rejected. Results land through LS.LIVE() cells backed by an RTD server instead.

  4. 04

    Let Excel cascade

    An RTD value landing marks its dependents dirty, so Excel recalculates downstream on its own — a handful of live cells can trigger a full workbook refresh.

That only pays off where Excel does repeated work. Data tables re-run their whole dependency cone once per scenario cell — the IRR-by-price-and-multiple grid on your LBO is a classic case — and circular references, like a cash-sweep debt schedule, get iterated to convergence. Both get wired up to LS.LIVE. An ordinary linear formula gains nothing, since Excel still has to walk every precedent itself.

Nothing about your model changes

LudicrousSpeed never overwrites a formula in place, and every conversion it makes can be undone exactly, cell for cell.

  • No rewrites

    Read, not rewrite

    Excel doesn't allow anything to overwrite a formula cell's cached value in place — three different ways of doing it were tried and rejected. Nothing about your model is altered just by running Analyze or Recalculate.

  • Instant toggle

    Flip a table, not your file

    Convert to Live swaps a data table's cells for LS.LIVE, wired straight to the Rust engine. Restore Native puts the exact original table back, from the definition recorded the moment you converted it.

  • Clean handoff

    Hand off a normal workbook

    Restore Native before the file leaves your machine, and the next person opens an ordinary .xlsx. No add-in, no dependency, nothing to explain to your MD.

LudicrousSpeed is a Rust + IronCalc engine behind an Excel-DNA ribbon add-in. Source on GitHub.
