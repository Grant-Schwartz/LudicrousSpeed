# Fixtures

Synthetic M&A workbooks should cover:

- operating model formulas;
- debt schedule and interest calculations;
- returns analysis;
- one-variable and two-variable sensitivity tables;
- lookup-heavy assumptions pages;
- date serial arithmetic;
- unsupported-feature routing for VBA/UDFs, external links, circular references,
  and volatile formulas.

Place generated workbooks in `fixtures/generated`, which is ignored by git.
